A simple starting point

  1. Choose a stream. Set a process or subsystem predicate for the issue you are investigating.
  2. Narrow the history. Use shared filters and time ranges, then Find to move between matches.
  3. Keep the evidence. Inspect full record fields and export the relevant history.

Common questions

Does it import the entire system log history?

It saves records captured by the streams you run. It does not backfill the system log datastore.

Does filtering delete records?

No. Shared text and time filters change the view. Saved capture data remains available.
