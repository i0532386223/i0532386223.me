01 / Why it exists

Make the next experiment repeatable.

Install macOS from an Apple restore image, keep each machine in its own bundle, and return to a known state with snapshots. Console controls, file exchange, and diagnostics keep routine work within reach.

01

Build a clean environment

Create independent macOS machines from IPSW images, with explicit CPU, memory, disk, and guest setup options.

02

Use snapshots, clones, and saved sessions to return to a point in your experiment.

03

Work across the boundary

Control network, shared folders, and clipboard separately. Use Guest Tools and the CLI for repeatable workflows.

04 / Your data

Privacy,
in plain language.

Read the privacy policy ↗

  • Virtual-machine storage

    Disks, settings, snapshots, and saved memory are stored in local VM bundles. A bundle may contain all data from the guest system.

  • Shared resources

    Network, clipboard, and shared folders are separate controls. Enable the resources your experiment needs.

  • Transfers

    Restore image downloads contact Apple. Guest networking, shared files, and exports can move data outside a VM when you enable them.
