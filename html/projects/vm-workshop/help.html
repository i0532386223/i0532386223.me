A simple starting point

  1. Create. Choose a restore image and configure the virtual machine.
  2. Experiment. Work in its console and share only the host resources you need.
  3. Return or transfer. Use snapshots, clones, exports, and the CLI to carry the work forward.

Common questions

Does it use Apple Virtualization?

Yes. VMWorkshop is a native application built around Apple’s Virtualization framework for macOS guests on Apple silicon.

Can I automate the same machines?

Yes. The CLI works with the same VM bundles as the app.
