Common questions

Does it encrypt the protected folders?

The project controls file access through macOS Endpoint Security. Folder encryption is a separate protection mechanism.

How do the sample application rules work?

Application rules apply across the protected set. Allow permits changes in protect folders, while read only still applies. Full access is an explicit exception to read-only mode. The screenshots show a sample profile.

What should I include in a support request?

Include the app version, macOS version, and the type of operation. Replace private paths with sample paths.
