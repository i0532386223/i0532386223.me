01 / Why it exists

Make system behaviour visible.

When an operation crosses executables, helpers, and files, the useful answer is often in the relationship between events. Endpoint Security Inspector combines a journal, process information, event filters, and explicit policies in one place.

01

Follow the events

Filter captured events by type, process, path, and decision. Aggregate repeated activity when a sequence becomes noisy.

02

Inspect the context

Read complete event fields, process identities, parent relationships, arguments, and destination paths in the inspector.

03

Explore explicit rules

Configure monitored and blocked targets and event mutes. Keep policy decisions alongside the activity they explain.

04 / Your data

Privacy,
in plain language.

Read the privacy policy ↗

  • Local records

    Configuration and event history are kept locally. Records can include paths, user and process identities, arguments, and environment data.

  • System integration

    Capture uses a privileged Endpoint Security service. macOS requires the relevant entitlements and system permissions.

  • Exports

    Diagnostic exports may contain sensitive system metadata. Review them before sharing. Capture does not make private fields public.
