A simple starting point

  1. Choose the application. Add the model runner and review its discovered components.
  2. Define the boundaries. Set file permissions and network rules for that application profile.
  3. Review activity. Use the activity journal to understand access decisions and refine your rules.

Common questions

Can I use it with an existing local model runner?

Add the application and review its discovered components. Ask for a build suited to your model runner and macOS version.

Can file and network rules be managed separately?

Yes. They are separate parts of the same application profile. Keep saved rules with the workflow they describe.
